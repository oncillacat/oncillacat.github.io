A1 Objects & Assignment

In R, you store values in objects using the <- operator. Think of it as a labelled box holding a value.

Warning: Always use <-, not =. Using = inside function calls can cause subtle bugs.
R
# Assign a single value
absorbance_single <- 0.95

# Print by typing the name
absorbance_single

# Arithmetic on objects
absorbance_single * 2
# [1] 0.95 # [1] 1.9

A2 Vectors

A vector is the fundamental R data structure — a sequence of values of the same type. Create one with c().

Warning: If you mix types inside c(), R silently coerces everything to the most general type — no error is shown.
R
absorbance <- c(0.95, 0.8, 0.6, 0.43, 0.36, 0.21, 0.14, 0.08, 0.06)
experiments <- c("MTT", "BCA", "puromycin", "ROS")

# What happens when you mix types?
mixed <- c(1, "hello", TRUE)
class(mixed)
# [1] "character" ← everything coerced to character

A4 Functions & Arguments

R functions take arguments. Pass them by name for clarity — especially optional ones.

Tip: Use ?function_name to open the help page. Use args(function_name) to see the argument list quickly.
R
absorbance <- c(0.95, 0.8, 0.6, 0.43, NA, 0.21, 0.14, 0.08, 0.06)

# Named arguments — always prefer for optional args
round(mean(absorbance, na.rm = TRUE), digits = 2)
# [1] 0.44

A5 Subsetting

Use square brackets [] to extract elements — by position or by condition.

Interactive Subsetting

R
absorbance <- c(0.95, 0.8, 0.6, 0.43, 0.36, 0.21, 0.14, 0.08, 0.06)

# By position
absorbance[c(1, 3, 5)]

# By condition
absorbance[absorbance > 0.5]

# %in% operator
experiments <- c("MTT", "BCA", "puromycin", "ROS")
experiments[experiments %in% c("BCA", "ROS")]
# [1] 0.95 0.60 0.36 # [1] 0.95 0.80 0.60 # [1] "BCA" "ROS"

A6 Missing Data

R uses NA to represent missing values. NA is not zero — zero is a valid measurement.

Warning: Never use 0 for missing data. It corrupts your statistics silently.
R
x <- c(0.95, 0.8, NA, 0.43, 0.36, NA, 0.14, 0.08, 0.06)

mean(x)               # NA is contagious
mean(x, na.rm = TRUE) # correct way
is.na(x)
na.omit(x)
# [1] NA # [1] 0.4314286 # [1] FALSE FALSE TRUE FALSE FALSE TRUE FALSE FALSE FALSE # [1] 0.95 0.80 0.43 0.36 0.14 0.08 0.06

A7 Factors

Factors represent categorical data with a fixed set of levels. By default levels are alphabetical.

R
treatment <- c("MTT", "BCA", "puromycin", "ROS", "MTT", "BCA")
treatment_factor <- factor(treatment)

levels(treatment_factor)
nlevels(treatment_factor)

# Specify a custom order
treatment_ordered <- factor(treatment,
  levels = c("MTT", "BCA", "puromycin", "ROS"))
levels(treatment_ordered)
# [1] "BCA" "MTT" "puromycin" "ROS" ← alphabetical # [1] 4 # [1] "MTT" "BCA" "puromycin" "ROS" ← custom order

B4 Core dplyr Verbs

  • mutate() — add or modify columns
  • select() — keep specific columns
  • filter() — keep rows matching a condition
Tip: When using both filter() and select(), filter first so select() works on fewer rows.
R — mutate()
experiment_info <- mutate(experiment_info,
  mean_ABCD = rowMeans(cbind(A, B, C, D), na.rm = TRUE))

select(experiment_info, Treatment, mean_ABCD)
# Treatment mean_ABCD # MTT 0.9325 # MTT 0.8775 # BCA 0.795 # BCA 0.435 # puromycin 0.355 # puromycin 0.215 # ROS 0.135 # ROS 0.085
R — filter()
filter(experiment_info, Treatment == "BCA", A > 0.5)
# Treatment A B C D ... # BCA 0.80 0.79 0.81 0.78 ...

B5 The Pipe Operator

The pipe |> passes the output of one function directly into the next — eliminating nested calls and intermediate variables.

Three ways to write the same pipeline

R
experiment_info |>
  mutate(mean_ABCD = rowMeans(cbind(A, B, C, D), na.rm = TRUE)) |>
  filter(Treatment == "BCA") |>
  select(Treatment, mean_ABCD)
# Treatment mean_ABCD # BCA 0.795 # BCA 0.435

B6 Grouping & Summarising

R
experiment_info |>
  group_by(Treatment) |>
  summarize(mean_A = mean(A, na.rm = TRUE),
            sd_A   = sd(A,   na.rm = TRUE)) |>
  arrange(desc(mean_A))
# Treatment mean_A sd_A # MTT 0.915 0.0495 # BCA 0.615 0.255 # puromycin 0.285 0.106 # ROS 0.110 0.0424

C1 Linear Regression

Use lm(y ~ x) to fit a linear model. The ~ is R's formula notation: "y as a function of x".

R
absorbance    <- c(0.95, 0.8, 0.6, 0.43, 0.36, 0.21, 0.14, 0.08, 0.06)
concentration <- c(2000, 1500, 1000, 750, 500, 250, 125, 25, 0)

model <- lm(absorbance ~ concentration)
coef(model)

# Predict at concentration = 800
predict(model, newdata = data.frame(concentration = 800))
# (Intercept) concentration # 0.04882 0.00044 # [1] 0.4003 ← predicted absorbance at 800 µg/mL

C3 Scatter Plot & Smooth

geom_point() draws the data. geom_smooth(method = "lm") adds the fitted line.

R
ggplot(df, aes(x = concentration, y = absorbance)) +
  geom_point(colour = "#1A5276", size = 3) +
  geom_smooth(method = "lm", colour = "#148F77") +
  labs(title = "BCA Standard Curve") +
  theme_minimal()
